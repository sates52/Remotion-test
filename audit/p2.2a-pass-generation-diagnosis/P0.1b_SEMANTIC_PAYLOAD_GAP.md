# P0.1b — Semantic payload transport gap

**Verdict: `MINIMAL_TRANSPORT_PATH_FOUND`**

This is a design audit. It makes no code, render, production-config, Gate,
VisualContract, Vision, P5, thumbnail, or fixture mutation.

## Root cause

`DirectorAdapter` creates placeholder semantic labels, not narrative-specific
payload:

- contrast: `LEFT_POLE` / `RIGHT_POLE`
- equivalence: `SOURCE_DOMAIN` / `TARGET_DOMAIN`
- cause/effect: `TRIGGER` / `CONSEQUENCE`
- psychology: `DENIAL` / `REALIZATION`

The adapter receives `intent` but not the already-available `narrativeAtom`.
The planner therefore can apply a visible `shot`, `cast`, and `diagram`, but
has no actual atom-derived labels to bind to the existing rendered fields.

No existing render path reads `_semanticAdapter`, `semanticGrammar`,

`TARGET_DOMAIN` directly. Those remain provenance metadata.

## Minimal deterministic transport design

Pass the already derived `narrativeAtom` into `buildDirectorOverrides()` at
`plan-antidote.js:545-550`. The adapter deterministically derives a short
`semanticPayload` from atom fields and narration clauses; it does not call a
model and does not create a renderer component.

The planner consumes `semanticPayload` **only when `semanticAdapter.override`
is present**. Authored ART, authored diagram/concept, and already-valid
director compositions keep their present precedence.

| Grammar | Adapter payload | Existing scene field to populate | Existing visible result |
|---|---|---|---|
| contrast | `{leftLabel,rightLabel}` | two explicit `texts` at left/right split coordinates | named opposing poles on their respective halves |
| allegory equivalence | `{sourceLabel,targetLabel}` | two explicit `texts` at left/right split coordinates | named source and target domains on their respective halves |
| cause/effect | `{triggerLabel,consequenceLabel}` | `diagram.title`, `diagram.labels` | atom-specific Flow nodes |
| psychology | `{internalPoleA,internalPoleB}` | `diagram.title`, `diagram.labels` | atom-specific Spectrum poles |

`props` are not the minimum transport vehicle: an adapter does not have a
trusted atom-to-motif ontology, and guessing one would risk generic or
forbidden visual proxies. Existing director-selected props remain preserved
after forbidden-trope filtering.

## Minimal responsibilities by layer

1. **Adapter:** accept `atom`; build short deterministic labels; attach both
   `semanticPayload` and unchanged provenance to its result.
2. **Planner:** when `override` exists, project labels to existing `texts` or
   `diagram.labels`; preserve current authored/director values when no override.
3. **Renderer:** unchanged. It already renders the fields above.
4. **Gate/VisualContract:** unchanged. The payload remains audit provenance;
   no threshold or acceptance behavior changes.

## Precedence and exclusions

- Authored diagram/concept still short-circuits the adapter as now.
- An already-valid composition still wins; no adapter labels are injected.
- The planner must reject label candidates that are empty, generic placeholders,
  or forbidden-trope tokens, leaving the existing scene output intact rather
  than fabricating a proxy.
- `semanticPayload` is recorded below `_semanticAdapter` with the original
  `semanticConstraints`, allowing P2 to trace an observed pixel to its atom.

## Pixel claim boundary

This identifies a minimal deterministic transport path. It does **not** prove
that the selected labels or split composition are semantically adequate at
pixel level; that remains the purpose of P2's offline mute test.
