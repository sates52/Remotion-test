## Provenance

The 22 A verification records retain:

```text
atom → intent/provenance → payload → grammar → renderedPayload
```

under `_semanticAdapter` planning metadata. This traceability passes, but it
does not make the payload quality acceptable.

## Decision

Do not start P0.3 / 933-scene Gate rerun. The transport is proven, but the
deterministic payload extractor needs a bounded correction before its output is
allowed to influence a production candidate pool.
