## 4. Implementation plan (for review — NOT implemented)

**P1.5a — fallback restaging for solo-capable SAFE scenes (75 scenes on WWL).** In the planner's staging section, when the strategy record's requirement is `kind:"fallback"`, choose the shot from the measured-safe levers, preserving semantic facts: shot/1 stays shot/1 (single figure preserved — diorama's silhouette is the same one-person claim), cast identities preserved, `concept` (if present) becomes the diorama's environmental icon per the existing director path. **Only for heuristic beats** (authored shots are sealed by the staging lock — the strategy requirement must not override an authored composition; ordering stays: repair → requirement-aware staging → lock). The 24 two-person SAFE scenes are NOT blanket-restaged (see open questions).

**P1.5b — absence: strategy-aware copy/style only where copy exists (10 scenes) + arc nudge on strategy-flagged motifs.** Where the beat has heuristic copy and the strategy says CONTRAST_ABSENCE, the copywriter's existing negation→strike path is preferred; where there is no copy, the planner may set `arc: "shrink"|"closein"` on an existing strategy-relevant motif (a presence-fading lever already rendered) — **it never invents a text or a prop** (invariant: a strategy changes representation, never adds subjects).

**P1.5c — concrete (2 scenes): route the metaphor beat's shot through the director's existing concrete-concept path when the strategy demands it and no authored shot exists.**

**P1.5d — measurement, not pretending:** `closeUp` (0.917 measured) becomes an accepted fallback lever in `SAFE_FALLBACK_LEVERS` (order: diorama → closeUp), so two-person SAFE scenes can satisfy a measured lever without inventing a two-person diorama. `illustration` (0.800) / `medium` (0.845) stay OUT — sub-threshold. The 24 two-person scenes remain UNRESOLVED-hard until either the capability is measured (P1.7) or the operator accepts a policy.

Every change is plan-tagged in `_visualStrategy.staging` (what was restaged, from→to, why) — the same non-silent discipline as D's repairs. Firewall code untouched: P1.5 only makes the planner satisfy the requirements the firewall already enforces.
