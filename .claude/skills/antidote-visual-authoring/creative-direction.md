# Creative direction — what the operator's preferred scenes share (Antidote, authoring guidance)

For storyboard / single-relation authors. **Never shown to blind readers, describers or judges.** Source: the operator
picked 7 of 20 versions in the cycle-13 muted study (5 single-relation, 2 production; 8Y = C12 single-relation was the
favourite) — `dev/c15:audit/c15/operator-visual-preferences.md`. These are HYPOTHESES from one viewer: a direction to
try on new scenes, never a template, never a gate. A prettier scene that is read WRONG is not better.

## Principles (try them; drop them where the narration does not support them)
1. **Draw the sentence's nouns as big, familiar objects** (coin, trophy, flame, book, tank, dog). A person is best as the
   one who RECEIVES the effect, not as the whole scene. Two people talking + a caption lost in every liked pair.
2. **One accent, switched on by the cause.** The cause starts neutral and lights up when it acts (the renderer does this
   for single-relation scenes); nothing else on the stage is accent-coloured. A light accent on a light card fails
   (the renderer falls back to a readable red).
3. **Before and after in the same frame.** Leave a trace of the before state — a dashed old level, the dashed empty slot
   an object left, the dashed outline of what disappeared — so one still shows the change.
4. **Let the content travel** (8Y): when the narration moves something from one owner / place to another, move THAT
   object (moveTo) and leave its empty slot; a change of ownership reads as a story with a beginning, middle and end.
5. **Few steps, no camera move, no decorative motion.** One relation, at most 3–4 entities, labels ≤ 2 narration words.
   Production versions that held one static image for ~10 s lost; so did busy multi-step builds (cycle 12).
6. **A quote card only when the sentence itself is the point.** Quote cards helped agent comprehension but were never
   picked for quality — prefer a drawable object when the narration gives one.

## Pattern: an invisible cause ("once you stop resisting, the adrenaline clears")
A person + a ring cannot show "stop doing X" (radical-compassion 128: the effect read, the cause did not). Draw the
thing that STOPS as an object of its own, named from the narration — e.g. a `shield` labelled "resisting" — and let the
ONE event both remove it (`present: false`, it stays as a dashed outline) and change the effect (the adrenaline level
falls). The cause is now visible as the thing that goes away.

## Do not
- Reuse 8Y's coin / trophy / slot when the narration does not have them.
- Draw a negated or "without …" clause as the effect (deep-work 250: "without demanding focus" was read as "nature
  depletes focus"; the validator now refuses it).
- Mention any of this, the operator's picks, or which version is new to a blind agent.
