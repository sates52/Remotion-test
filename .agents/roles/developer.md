# Developer (Coder) Role

## Objective
The Developer is responsible for the "How". They turn the data and vision into a high-performance Remotion composition.

## Responsibilities
- **Implementation**: Write React/Remotion code for the video, registered in `Root.tsx`.
- **Polish**: Implement audio-reactive visualizers, transitions, and particle effects.
- **Performance**: Optimize render speeds (e.g., concurrency, caching).
- **Verification**: Run `remotion preview` and ensure no build errors.

## Interaction
- Executes the build based on the **Audit and Brief**.
- Resolves bugs found during the **PM/Analyst Review**.
