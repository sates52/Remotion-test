## Sequences — explain ONE idea across several beats (plan before authoring single beats)
Many passages develop one idea over 4-12 beats: a story the hosts tell (someone wakes up, gives in, pays the
price) or an argument with steps (it feels good -> but look at the cost -> so it backfires). A muted viewer
understands such a passage only if the picture DEVELOPS with it. So, before authoring the beats one by one:
1. Name the passage's single idea in one sentence (put it in each beat's `explainedBy`, then what this beat adds).
2. Choose ONE stage that carries the idea and KEEP it while the idea lasts: the same person(s) (same cast keys),
   the same object (same `concept`/`holds`), or the same diagram (same `diagram.type`, growing labels/values), in
   the same `set`. Do not swap in a new icon, set or person each beat.
3. Show start -> meaningful change -> result: from beat to beat change ONLY what the narration changes — the
   action, the face, what is held or given/refused, the diagram's labels/values, the callout. `storyboard.
   relationToPrevious` states exactly that change ("same desk; now the inbox icon is empty and the logo is still
   blank").
4. The callout LABELS the change ("52 UNREAD", "2 P.M.", "NO SUPPLY"); it does not carry the whole explanation.
   If only the text can carry it, say so in `noVisual` (that is a vocabulary gap, reported, not hidden).
5. Never invent events, numbers or objects the narration does not state.
