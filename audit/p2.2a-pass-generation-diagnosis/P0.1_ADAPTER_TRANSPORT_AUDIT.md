# P0.1 — DirectorAdapter → Antidote transport audit

**Verdict: `PARTIAL_TRANSPORT`**

This is a code-path and metadata audit only. No render, production config,
VisualContract, Gate, Vision, P5, thumbnail, or Flux path was changed.

## What is proven

The adapter is invoked after `director.direct()` and before the planner assembles
the `rawScene` (`scripts/plan-antidote.js:545-551`). Its visible direction
overrides are consumed:

| Adapter output | Planner transport | Renderer consumer | Result |
|---|---|---|---|
| `shot: "split"` | `rawScene.shot` (`plan-antidote.js:752`) | `shotPreset(scene.shot)` (`Scene.tsx:220`) | visible split field and two shot slots |
| `cast.count`, roles, secondary action | planner creates `characters[]` (`plan-antidote.js:615-635`) | `stageChar()` / Everyman bodies | visible two-character staging/actions |
| `diagram: flow` / `spectrum` | diagram branch forces `insert`, zero cast and empty props (`plan-antidote.js:572-579`) | `<Diagram spec={scene.diagram}>` (`Scene.tsx:305-316`) | visible flow / spectrum graphic |
| filtered props | planner emits `props` (`plan-antidote.js:655-675,757`) | `<Motif>` mapping (`Scene.tsx:264-303`) | visible motif change when props remain |
| `forbiddenTropes` | `sanitizeAction()` reads transported constraints (`plan-antidote.js:626-629`) | character action | `celebrate` can be changed before scene metadata |

## What is not proven / not consumed by the renderer

`semanticGrammar` and `semanticConstraints` are copied to
`rawScene._semanticAdapter` (`plan-antidote.js:736-747`) for audit provenance.
The Antidote renderer has no read of `_semanticAdapter`, `LEFT_POLE`,
`RIGHT_POLE`, `SOURCE_DOMAIN`, or `TARGET_DOMAIN`.

Therefore the current adapter demonstrably changes **composition grammar**, but
does not yet bind its symbolic pole/domain labels to distinct visual subjects.
This is precisely a P2 mute-test question, not evidence for a P0 Gate or
planner change.

## Conclusion

`PARTIAL_TRANSPORT` is the only evidence-supported status:

- The adapter's shot/cast/diagram/props decisions do change the emitted scene
  shape and are consumed by Antidote rendering.
- Provenance survives in emitted metadata for a later audit.
- Symbolic pole/domain names do not yet drive different content on either side
  of a split. Pixel adequacy remains unproven until P2's offline mute test.
