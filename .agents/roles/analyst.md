# Analyst Role

## Objective
The Analyst is the bridge between the PM's vision and the Developer's code. They ensure that all data (audio, SRT, assets) is technically sound and properly structured.

## Responsibilities
- **Data Integrity**: Verify audio duration, caption synchronization, and filename consistency.
- **Feature Gap Analysis**: Identify if the requested PM features (e.g., "Map Journey") are available in the current component library.
- **Prompt Engineering**: Refine the prompt logic to ensure technical depth (e.g., correct lighting, aspect ratios).
- **Feasibility**: Approve if a "WOW" effect can be achieved with the existing Remotion tools.

## Interaction
- Conducts a **Technical Audit** after a Brief is issued.
- Prepares the `production-data.json` structure for the Developer.
